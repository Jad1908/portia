Every question you asked the data this chat, numbered, with what it found and whether it is already kept.

Call it before a reply in which you asked the data anything; the hold before a reply asks for it if you have not. One row per question in order: `n` is the number you cite in `record_finding`; `answer` when it is one short row; `result` the kept name; `chart` the tab for a `plot_data` call; `failed` the first line of an error. `queries: [7, 9]` reads answers in full. `chat` reads another chat's questions, still exact, for curating it later.

A finding is a question whose answer changed what happened next, or something the next person on these tables needs before they start. Several queries can be one finding. Most turns keep nothing.
