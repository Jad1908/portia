Write what you know about a table into its catalog entry: a `summary`, `roles` per column, a `note`. Judgment only; measured facts do not change.

`summary` says what the table is in the project's terms, one paragraph, replaced whole by a later call. `roles` maps a column to identifier, measure, timestamp, category, free_text, or a word the project uses; a key holding `*` or `?` is a pattern (`"*": "measure"`), an exact name wins over a pattern, and the pattern with more plain characters wins. `note` is one sentence appended, dated, never rewritten: what someone building on this table has to know first ("outcome is a letter grade, not pass/fail"). Works on a model by its name; a model you just built has facts and no summary until you write one.
